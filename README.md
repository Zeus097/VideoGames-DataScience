# Video Games Data Science Analysis

## Objective
The goal is to analyze the factors influencing the success of video games.

## Datasets
- Video_Games_Sales_as_at_22_Dec_2016.csv  
    used as the main dataset for measuring game data(1 of 3)
    source: [Video Games Sales Dataset](https://www.kaggle.com/datasets/sidtwr/videogames-sales-dataset)

- games.csv  
    Steam dataset used for additional metadata such as genres, ratings, and reviews
    source: [SteamGames(71k games)](https://www.kaggle.com/datasets/mexwell/steamgames)

## Project Structure
- data/ 2 datasets
- notebooks/ analyzes written on Jupyter Notebook

## Notes
- No web scraping is used
- The structure is intentionally simple at this stage
